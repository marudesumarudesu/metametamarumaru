# AI Metaverse Market Lobby

This project builds the lobby space first.
The center of the room is a giant live market information board, and the plaza around it is prepared for future avatar gathering.

## Files

- `index.html`: lobby layout and live market board
- `styles.css`: sci-fi plaza, walkways, gates, and responsive styling
- `app.js`: market session cards, clocks, dock pads, share UI, and theme switching

## Usage

1. Open `index.html` in a browser
2. Stay online so the embedded market widgets can load current data
3. Share the page URL if you want multiple people to open the same lobby

## Notes

- The current version focuses on the space itself, not visible avatars yet
- The dock pads are visual placeholders where avatars can be added later
- Static hosting such as GitHub Pages or Netlify is a good fit for sharing
